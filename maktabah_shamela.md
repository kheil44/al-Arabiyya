Welcome to Al-Maktaba al-Shamela! It is an incredible tool for studying Arabic and Islamic texts. [1] 
Since Arabic reads from right to left, the application layout and the icon text read in that exact order. Here is the literal meaning and technical function of every button shown in your toolbar screenshot, moving from right to left: [2] 
------------------------------
## The Main Navigation Toolbar (Right to Left)

| Icon/Text | Literal Arabic Meaning | Software Function / Technical Term |
|---|---|---|
| كتاب | Book | Choose Book / Browse Library: Opens the primary menu to browse categories and pick a specific book to read. |
| القرآن | The Qur'an | Holy Qur'an Screen: Opens the dedicated view for reading the text of the Qur'an alongside its associated commentaries (Tafsir). |
| البحث | The Search | Advanced Search Engine: Opens the main search dashboard where you can run complex query terms, filter by categories, or scan multiple texts. |
| التحكم | The Control | Control Panel: Allows you to import external books, edit existing text files, or manage database custom entries. |
| المراجع | The References / Bibliographies | Author & Book Cards Info: Displays detailed biographical metadata regarding the book's author, publisher, publication date, and description. |
| مذكرات | Notebooks / Memos | Clipboard History / Scratchpad: A cumulative copy utility that saves clips or custom notes you make while reading. |
| جلسات | Sessions | Workspace Sessions Manager: Saves your current workspace (open tabs and windows) so you can close the software and return to the exact same setup later. |
| النوافذ | The Windows | Window Manager: Standard dropdown to arrange, tile, or switch between your open inner book sub-windows. |
| الخيارات | The Options | Settings Panel: Standard software preference menu to change fonts, interface themes, or default download pathways. |
| راسلنا | Contact Us | Support / Feedback Link: Launches a browser window to email the official Shamela development team with bugs or feedback. |
| ساهم | Contribute | Donation / Volunteer portal: Directs you to their contribution page to support the project. |

------------------------------
## The Search Inputs (Left Side)
On the far left side of your screenshot, there is a numeric indicator and a fast input bar:

* 
* الرقم الأحمر (٨٥٩٨): This badge counter indicates the total number of books currently downloaded and ready inside your offline library database.
* بحث إجمالي في جميع الكتب: This translates literally to "Global Search Across All Books." It acts as a rapid global search bar. Typing a phrase directly here and hitting enter initiates a broad text query across your entire digital collection. [3]
